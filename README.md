# Greenscape Pro Quote-to-Proposal Agent

AI take-home submission for the License & Scale AI Developer role.

The project builds the P0 agent recommended in the strategy document: a human-in-the-loop proposal drafting workflow for Greenscape Pro. It turns Marcus's site-walk notes into a structured proposal draft, persists the workflow in Postgres, and sends a Slack review notification.
